## 🎯 Универсальная формула идеального промта
Чтобы ИИ ответил идеально, используй эту структуру:
1. **Роль:** Кем должен быть ИИ? (Пример: "Ты опытный программист...")
2. **Контекст:** Какая ситуация? (Пример: "У меня слабый ноутбук и я учусь с нуля...")
3. **Задача:** Что конкретно сделать? (Пример: "Напиши простой код для...")
4. **Ограничения:** Чего делать нельзя? (Пример: "Не используй сложный жаргон...")
5. **Формат ответа:** В каком виде выдать результат? (Пример: "Ответь по пунктам...")

## 🤖 Промт-шаблон для создания простого ИИ-Агента
Скопируй этот текст и вставь в ChatGPT/Claude, чтобы превратить его в личного ИИ-ассистента:
> "Ты — ИИ-Агент, эксперт по обучению новичков. Твоя цель — помогать пользователю осваивать технологии. Отвечай просто, как новичку, давай примеры из реальной жизни и предлагай решения"
